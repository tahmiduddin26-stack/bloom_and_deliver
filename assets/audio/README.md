# Audio Assets

Drop these files here to enable sound:

| File | Used for |
|------|----------|
| `ambient_shop.mp3` | Looping background ambience (soft, cozy shop sounds) |
| `flower_drop.mp3` | Flower dragged into workspace |
| `submit.mp3` | Bouquet submitted |
| `great_order.mp3` | Happy jingle on "great" result |
| `poor_order.mp3` | Soft sad sound on "poor" result |
| `coin.mp3` | Coin earned / challenge complete |
| `notification.mp3` | In-game notification sound |

Recommended: ~44.1kHz stereo MP3, kept under 200 KB each.
The AudioService silently ignores missing files so the game runs without them.
